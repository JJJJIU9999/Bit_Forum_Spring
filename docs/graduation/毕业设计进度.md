### M2：文章草稿、审核、发布、下架状态流转

当前状态：已完成实现和验证，尚未提交。

已完成：

- `article` 表新增 `status` 字段，已有文章迁移后默认 `PUBLISHED`。
- 新增 `article_audit_record` 表记录审核通过、驳回和下架操作。
- 新增文章状态：`DRAFT`、`PENDING`、`PUBLISHED`、`REJECTED`、`OFFLINE`。
- `/api/article/publish` 保留旧路径，语义调整为“提交审核”，新文章进入 `PENDING`。
- 新增草稿保存、草稿更新、提交审核、作者文章列表接口。
- 新增管理员审核列表、审核通过、审核驳回、下架接口。
- 公开文章列表、详情、浏览、点赞、热门文章只处理 `PUBLISHED`。
- 审核通过后才发送 RabbitMQ 文章发布消息。
- 驳回必须记录原因，下架会清理文章 Redis 数据。
- 前端发布页调整为“提交审核 / 保存草稿”，新增“我的文章”状态列表，管理员面板新增审核和下架操作。

### M3：收藏与基础搜索

当前状态：已完成实现和验证，尚未提交。

已完成：

- 新增 `article_favorite` 表，用于记录用户收藏文章。
- 新增 `ArticleFavorite` Entity 和 `ArticleFavoriteMapper`。
- `Article` 响应补充 `favoriteCount`。
- 用户只能收藏 `PUBLISHED` 文章。
- 同一用户不能重复收藏同一篇文章。
- 用户只能取消自己的收藏。
- 我的收藏只返回当前用户收藏且仍为 `PUBLISHED` 的文章。
- 下架文章不会出现在普通我的收藏列表中。
- 新增基础搜索接口，支持按标题和正文关键词搜索。
- 搜索只返回 `PUBLISHED` 文章。
- 搜索支持 `categoryId` 筛选。
- 收藏、取消收藏、我的收藏接入现有 JWT + Interceptor 登录拦截。
- 公开搜索不需要登录。
- 前端文章列表支持关键词搜索和板块组合筛选。
- 前端文章详情支持收藏数展示、收藏和取消收藏。
- 前端“我的”页面支持“我的文章 / 我的收藏”切换。

### M5：举报与内容治理

当前状态：已完成实现和验证，尚未提交。

已完成：

- 新增 `content_report` 表，用于记录用户举报文章或评论。
- 新增 `ContentReport` Entity 和 `ContentReportMapper`。
- 新增举报状态：`PENDING`、`RESOLVED`、`REJECTED`。
- 新增举报对象类型：`ARTICLE`、`COMMENT`。
- 用户只能举报他人的已发布文章。
- 用户只能举报他人的评论，且评论所属文章必须存在并处于 `PUBLISHED`。
- 同一用户不能对同一对象重复提交待处理举报。
- 已处理举报后，允许用户再次举报同一对象并生成新记录。
- 用户可分页查看自己的举报记录。
- 管理员可按状态分页查看举报。
- 管理员可将举报处理为成立或驳回，并记录处理人、处理说明和处理时间。
- 普通用户不能访问管理员举报处理接口。
- 未登录用户不能提交举报或查看自己的举报记录。
- 前端文章详情页支持举报文章和举报评论。
- 前端“我的”页新增“我的举报”列表。
- 前端管理员面板新增“举报处理”页签。
- 补充 M5 相关后端测试。
- 更新 M5 计划、调查和进度文档。

### M6：管理员数据统计看板

当前状态：已完成实现和验证，尚未提交。

已完成：

- 新增 `AdminDashboardService`，通过现有表实时 count 聚合统计。
- 统计用户总数、普通用户、管理员、启用用户、禁用用户。
- 统计文章总数、`DRAFT`、`PENDING`、`PUBLISHED`、`REJECTED`、`OFFLINE`、今日新增和最近 7 天新增。

- 统计举报总数、`PENDING`、`RESOLVED`、`REJECTED`、今日新增和最近 7 天新增。
- Redis 热门文章 Top 10 只返回仍为 `PUBLISHED` 的文章。
