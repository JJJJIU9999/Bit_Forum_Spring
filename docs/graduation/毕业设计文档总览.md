# 毕业设计文档总览

## 项目名称

基于 Spring Boot 与 React 的社区交流平台设计与实现

## 文档定位

本文是 `docs/graduation/README.md` 的中文替代文件，用于记录毕业设计改造的总体目标、当前能力、模块路线和文档入口。

项目当前不是要重构成微服务，也不是单纯堆技术，而是在现有 `bit-forum-spring` 轻量论坛基础上，逐步补齐社区系统的完整业务闭环：

```text
内容发布
-> 板块组织
-> 审核发布
-> 用户互动
-> 通知反馈
-> 举报治理
-> 后台统计
-> 用户个人中心
```

## 当前已实现能力

### 用户与认证

- 用户注册。
- 用户登录。
- BCrypt 密码哈希。
- JWT 登录认证。
- `LoginInterceptor` 校验写接口。
- 注册响应脱敏，不返回 `password`。
- 用户角色：`USER` / `ADMIN`。
- 用户状态：启用 / 禁用。
- 禁用用户不能重新登录。

### 管理员权限

- `AdminInterceptor` 拦截 `/api/admin/**`。
- 从 JWT 获取 `userId`。
- 回查数据库校验用户是否存在。
- 校验用户状态是否启用。
- 校验用户角色是否为 `ADMIN`。

### 文章、评论与 Redis

- 文章发布、修改、删除、详情、分页。
- 评论发布与查询。
- 浏览量统计。
- 点赞与取消点赞。
- 热门文章排行。
- 浏览、点赞、评论前校验文章存在。
- 删除文章时清理评论与 Redis 数据。

Redis 当前用途：

- String：文章浏览量。
- Set：点赞去重。
- ZSet：热门文章排行。
- Set：RabbitMQ 消费幂等 `messageId`。

### RabbitMQ

- 文章发布异步消息。
- 生产者 ConfirmCallback。
- ReturnsCallback。
- `mandatory` 投递失败回调。
- 消费者手动 ACK。
- `basicNack(requeue=false)`。
- DLX / DLQ。
- Redis 幂等消费。

### 管理员模块

- 管理员健康检查。
- 管理员分页查看文章。
- 管理员删除任意文章。
- 管理员分页查看评论。
- 管理员删除任意评论。
- 管理员分页查看用户。
- 管理员启用 / 禁用用户。
- 管理员不能禁用自己。
- 用户列表脱敏，不返回 `password`。

## 统一实现约束

每个模块继续使用现有项目风格：

```text
Controller
Service
Mapper
Entity
DTO
Interceptor
Config
Exception
Result<T>
```

必须保持：

- MyBatis-Plus。
- Flyway。
- Redis。
- RabbitMQ。
- JWT + Interceptor 权限方案。
- 统一 `Result<T>` 返回结构。
- Jakarta Validation。
- 简单 React / Vite 前端结构。

不要引入：

- Spring Security。
- Spring Cloud。
- Elasticsearch。
- Kafka。
- 复杂权限表。
- 复杂菜单权限。
- 分布式事务。
- Redux / Zustand。
- 复杂 UI 组件库。

## 每个模块完成标准

每完成一个模块，必须做到：

1. 新增数据库变化必须有新的 Flyway migration。
2. Entity、DTO、Mapper、Service、Controller 分层清晰。
3. 使用统一 `Result<T>`。
4. 参数使用 Jakarta Validation。
5. 权限校验正确。
6. 不返回 `password` 等敏感字段。
7. 关键异常有明确提示。
8. 补充后端测试。
9. 后端运行 `mvn test`。
10. 涉及前端时运行 `npm run build`。
11. 更新 `docs/graduation/` 下对应模块文档。
12. 输出修改文件清单、验证结果、风险和待确认事项。
