# 前端整体重构任务计划

## 目标

在不改变既有论坛业务接口和数据库结构的前提下，将 React 前端重构为暖色编辑社区风格，并解决当前无 URL 路由、移动端不完整、可访问性不足和页面层级松散的问题。

## 已确认决策

- 工作分支：`feat/frontend-refactor`。
- 视觉方向：暖色编辑社区；保留米白、砖红、苔绿的品牌基调，采用内容优先的排版。
- 改造范围：登录注册、公共社区、个人中心、通知和管理后台全部覆盖。
- 路由：使用 React Router 声明式路由；用户状态仍以现有 Axios API 和后端拦截器为最终权限来源。
- 最小后端配合：`LoginResponse` 新增 `role`，仅用于前端显示管理员入口；不新增数据库字段或 Flyway 迁移。
- 依赖边界：仅新增 `react-router`、`lucide-react` 和前端测试所需的 Vitest/Testing Library；不引入 UI 框架、Redux/Zustand、图表库或动画库。

## 路由目标

- 公共：`/`、`/articles/:articleId`、`/users/:userId`、`/login`、`/register`。
- 登录后：`/publish`、`/notifications`、`/me/profile`、`/me/articles`、`/me/favorites`、`/me/reports`。
- 管理端：`/admin`、`/admin/audit`、`/admin/articles`、`/admin/comments`、`/admin/reports`、`/admin/users`、`/admin/categories`。
- 首页关键词、板块和页码存入查询参数；游客访问受保护页面时携带 `redirectTo` 前往登录页。

## 约束

- 保留两份未跟踪学习文档，不删除、不覆盖、不暂存。
- 不修改历史 Flyway V1-V11，也不修改 M1-M12 的历史模块日志。
- 文章、评论、收藏、关注、通知和后台接口保持兼容；管理员权限仍由后端 `AdminInterceptor` 校验。
- 不自动提交或推送。

## 验收标准

- 核心页面可通过稳定 URL 直接打开、刷新和前进后退。
- 360、375、768、1024、1440px 下无页面级横向滚动。
- 键盘可操作导航、表单和弹窗；所有页面有一个 `h1`，弹窗支持 Escape 与焦点恢复。
- `npm run test`、`npm run build`、`mvn -Dtest=UserControllerTest test`、`mvn test`（本地服务就绪时）和 `git diff --check` 通过。
