Troubleshooting:

| Symptom | Finding | Resolution |
| --- | --- | --- |
| Register page showed `Network Error` | `localhost:8080` was not accepting TCP connections, so Vite could not proxy `/api` to Spring Boot | Start the backend first, then restart/refresh the frontend |
| `npm run build passed` failed with `Could not resolve entry module "passed/index.html"` | `passed` was treated as an extra Vite build argument | Use exactly `npm run build` |
| `mvn spring-boot:run` ended with `BUILD FAILURE` | Running without required environment variables can make Spring Boot exit during startup | Set `SPRING_DATASOURCE_PASSWORD`, `SPRING_RABBITMQ_PASSWORD`, and `JWT_SECRET` before running |
| CMD printed `The filename, directory name, or volume label syntax is incorrect.` for `$env:...` commands | `$env:NAME='value'` is PowerShell syntax, but the terminal prompt was CMD (`D:\...\>`) | In CMD use `set NAME=value`, or open PowerShell and use `$env:NAME='value'` |
| Spring Boot failed with `WeakKeyException: key byte array is 104 bits` | The JWT secret actually loaded by the app was too short because the intended env var was not set | Use a JWT secret at least 32 bytes long and set it with the correct shell syntax |

Follow-up change:

- Improved frontend network error text in `frontend/src/api/request.js`.
- New message: `无法连接后端服务，请确认 Spring Boot 已在 8080 端口启动。`

Verification after follow-up:
