# Phase 2 React Frontend Findings

## Backend API Summary

All normal backend responses use:

```json
{
  "code": 200,
  "message": "message",
  "data": {}
}
```

Frontend handling rule:

- `code === 200`: business success.
- `code !== 200`: business failure, show `message`.
- HTTP `401`: not logged in or token invalid.
- HTTP `403`: no permission or account unavailable.

## Admin Interfaces

All admin interfaces require admin JWT:

```text
Authorization: Bearer <admin-token>
```

```text
GET    /api/admin/health
GET    /api/admin/article/page?pageNum=1&pageSize=10
DELETE /api/admin/article/delete?articleId=1
GET    /api/admin/comment/page?pageNum=1&pageSize=10
DELETE /api/admin/comment/delete?commentId=1
GET    /api/admin/user/page?pageNum=1&pageSize=10
PUT    /api/admin/user/disable?userId=2
PUT    /api/admin/user/enable?userId=2
```

Important permission finding:

- `/api/admin/**` is protected by `AdminInterceptor`.
- The interceptor checks JWT, latest user status, and `role=ADMIN`.
- Frontend cannot be the real permission boundary.

## Axios Request Layer Design

New request files:

```text
frontend/src/api/request.js
frontend/src/api/userApi.js
frontend/src/api/articleApi.js
frontend/src/api/commentApi.js
frontend/src/api/adminApi.js
```

Design:

```text
request.js
-> creates one axios instance
-> uses baseURL /api
-> reads token from localStorage
-> adds Authorization: Bearer <token>
-> unwraps backend Result responses
```

Vite proxy:

```text
Browser calls /api/user/login on localhost:5173
-> Vite dev server proxies /api to http://localhost:8080
-> Spring Boot receives /api/user/login
```

Why use `/api` as `baseURL`:

- Keeps frontend code independent from the backend host during development.
- Avoids browser CORS problems while Vite dev server is running.
- Still matches backend controller paths.

Auth storage keys:

```text
bit_forum_token
bit_forum_user
```

Dependency:

```text
axios
```

The user should install it from `frontend/`:

```powershell
npm install axios
```

## Login And Register Page Flow

New page files:

```text
frontend/src/pages/Login.jsx
frontend/src/pages/Register.jsx
```

`App.jsx` responsibilities now:

```text
-> tracks active page: login/register
-> reads current user from localStorage on startup
-> shows current login status
-> clears token on logout
-> renders Login or Register page
```

Login flow:

```text
User fills username/password
-> Login.jsx calls loginUser(form)
-> userApi.js calls request.post('/user/login')
-> request.js sends POST /api/user/login
-> backend returns data.token/userId/username
-> saveAuth stores token and user info in localStorage
-> App updates current user display
```

Register flow:

```text
User fills username/password
-> Register.jsx calls registerUser(form)
-> userApi.js calls request.post('/user/register')
-> backend creates user
-> page switches back to login
```

Local storage keys:

```text
bit_forum_token
bit_forum_user
```

